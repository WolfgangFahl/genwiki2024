# Wiki Playgrounds

## Overview
- **URL**: https://wiki-playground.genealogy.net/ - hosts Semantic MediaWiki playgrounds
- **Generator**: `playground.py` in the genwiki2024 repository
- **Control Script**: `~/bin/setup_wikis` - main control script for managing wikis
- **Git Repository**: git@github.com:WolfgangFahl/genwiki2024.git
- **Project Location**: ~/source/python/genwiki2024

## System Details
- **Number of wikis**: 44 different docker-based MediaWiki instances
- **Base port**: 9100 (each wiki uses ports with step of 2)
- **Host**: wiki-playground.genealogy.net
- **Protocol**: HTTPS

## Generator: playground.py
Located at: `genwiki/playground.py` in the genwiki2024 repository

The `playground.py` script generates configurations for 44 wiki playgrounds based on Greek gods. Each wiki is named after a Greek deity.

### Key Features:
1. **Apache/Caddy Configuration**: Generates reverse proxy configurations
2. **Index Page**: Creates HTML index with all 44 wikis displayed in a grid
3. **Setup Script**: Generates bash scripts to create and configure wikis
4. **Patch Script**: Fixes MediaWiki configuration for proper HTTPS support

### Usage:
```bash
python -m genwiki.playground --help
python -m genwiki.playground --index    # Generate index.html
python -m genwiki.playground --caddy    # Generate Caddy configuration
python -m genwiki.playground --setup    # Generate setup script
python -m genwiki.playground --patch    # Generate patch script
python -m genwiki.playground --list     # List all 44 Greek gods
```

## Control Script: setup_wikis
Located at: `~/bin/setup_wikis`

This is the main control script that manages the 44 wiki playgrounds. It uses the `profiwiki` tool to create and manage docker-based MediaWiki instances.

### Common Operations:
```bash
# Show help
setup_wikis -h

# List all wikis
setup_wikis -l

# Start all wikis
setup_wikis -s

# Stop all wikis
setup_wikis -x

# Update all wikis
setup_wikis -u

# Check status of all wikis
setup_wikis -c
```
